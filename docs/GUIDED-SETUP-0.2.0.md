# Start here — version 0.2.0

Install the new APK over the old one. Choose **Update** if Android asks. You do not need to uninstall or remove your widget.

Open **Home Alignment Lab**. It now shows the next incomplete step, one screen at a time. If an existing widget is already installed, the app keeps it and skips adding another.

## 1. Choose a background

Tap **Use the simple test grid** for the easiest first test. Or choose a photo. Neither choice needs the optional broad storage permission. The next step changes your home wallpaper, so keep your original picture if you want to restore it later.

## 2. Turn on the wallpaper

Tap **Open wallpaper preview**. On Android's screen, tap **Set wallpaper** or **Apply**. Select **Home screen** if asked. Return to Home Alignment Lab.

The app checks whether its wallpaper was actually applied. Simply opening the preview or pressing Back does not complete this step. The preview shows only the background, not a pink box yet.

## 3. Add one widget

Tap **Add the test widget** and accept Android's placement prompt. If the launcher does not offer this, long-press an empty home-screen area, open **Widgets**, and drag **Home Alignment Lab** onto the screen. You only need one widget for this first check.

If you already have a test widget, the app skips this step.

## 4. Show the pink box

Go home and tap the centre of the yellow-outlined widget. Tap **Show pink box**. The app returns home. If Home opens another page, swipe back to your widget.

A pink box with cyan edges should appear behind the yellow outline. It stays for 45 seconds after the first frame is drawn. Look at all four straight edges.

If the wallpaper is not applied, the app takes you back to setup instead of offering a nonworking test button. If the position or wallpaper has changed, the app explains that you need a fresh tap.

## 5. Tell the app what happened

Tap the widget again after looking. Choose:

- **Yes — it lined up**
- **I saw it, but it was misplaced**
- **No pink box appeared**

If the box was missing or misplaced, use **Save report for troubleshooting**, save the text file in Downloads, and attach it in our chat with a screenshot if available. You do not need to interpret the technical values yourself.

## After the first check

The **Next: check other home-screen pages** button starts a separate guided check. It first explains how to prepare three pages with one widget each, then shows one visit at a time: A → B → C → C → B → A. Each widget tap asks you to confirm and save the named visit. Different repeatable readings only make the launcher a candidate; you must still watch for a pink box on the wrong page while swiping.

**Help & saved report** contains progress, report export and optional advanced tools. Raw coordinates and old diagnostic tabs are kept there for investigation; they are not required for the first setup.

Video is still deliberately deferred. This update fixes the setup and diagnostic experience; it does not establish OnePlus rendering or page-isolation support without actual phone results.
