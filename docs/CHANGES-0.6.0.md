# Changes — 0.6.0-multi-widget

- **Multiple independent animated widgets**: Up to four widgets enabled simultaneously on the home screen, each with its own file selection, pending preview, playback source, stop, location, display mode, tap action, error and telemetry state.
- **Single-surface multi-layer EGL compositor**: One OpenGL ES 2.0 wallpaper surface renders the background plus up to four independent GIF textures and hardware-decoded video `SurfaceTexture` layers. Each layer respects page, zoom, and visibility gates and pauses independently. A media decode failure disables only its widget; a surface/EGL failure stops the renderer.
- **Normal single-tap automatic placement**: Compatible measured launcher scale is reused automatically on ordinary taps. The two-corner and pink-box tools are now optional per-widget troubleshooting (`Troubleshoot this widget`). A/B/C page surveys are no longer a prerequisite for personal playback.
- **Three-step first-time flow and My widgets dashboard**: Switching files does not redo setup; moving or resizing a widget only needs a fresh ordinary tap. When an active widget is resized, its yellow outline automatically reappears with a `"Tap to update size"` prompt and hides again once tapped.
- **Separate GIF/video document pickers & strict file verification**: Separate `image/gif` and `video/*` document pickers (`EXTRA_LOCAL_ONLY`), actual magic-header content validation, private-copy live previews, and explicit confirmation. Import failure blocks silent fallback. Confirmed source snapshots bind the renderer to the exact saved copy.
- **Upgraded real-world GIF support**: Supports GIFs up to 1920 × 1920 pixels, 600 frames, and 120M canvas-pixels while capping the offscreen GPU texture canvas to <= 512 px (< 1 MB heap per GIF). Parses GIF89a Graphic Control Extension frame delays so GIFs where Android's `Movie.duration()` returns `0` still animate properly in both preview and wallpaper playback.
- **Per-widget Display Modes (`Fit` / `Fill` / `Fit with black bars`)**: Each widget can independently display its GIF or video using **Fit inside (wallpaper edges)** (no black bars in empty widget margins), **Fill widget (center crop)** (edge-to-edge UV crop without stretching), or **Fit inside (black bars)**.
- **Per-widget Folder Popup Compatibility**: Fixed folder tap mode so tapping a widget to open app shortcuts updates its location without wiping automatic placement or stopping its animation, and added per-widget tap action controls right in `VideoActivity` and `FolderActivity`.
- **Current/system static wallpaper option**: Added to the background flow with explained optional Android file/photo permissions and a zero-permission photo-picker alternative.
- **Migration & storage hygiene**: Existing 0.5.0 saved media migrates automatically to the established widget; startup cleanup retains every widget's selected, pending and playback files.
