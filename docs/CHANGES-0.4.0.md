# 0.4.0 — bounded video experiment

The user's 0.3.0 OnePlus report establishes successful observed alignment and page isolation for the tested setup (see ONEPLUS-0.3.0-RESULT.md). This update implements the previously gated video experiment, not a finished media library.

- Bundled, locally generated silent H.264 clip: 640 × 360, 300 frames, 30 FPS, exactly 10 seconds. It loops within the measured page-A rectangle; fitting the entire clip preserves its aspect ratio with black bars where needed.
- A dedicated EGL/OpenGL ES thread owns each wallpaper surface throughout its lifetime. Existing grid/photo and pink-box scenes are drawn to an offscreen bitmap only when changed and uploaded as a static GPU texture. MediaCodec decodes to a SurfaceTexture/external OES texture, which is composited inside the widget. Video never replaces the surrounding background or uses an overlay/Activity substitute.
- Hardware-accelerated decoders are preferred when the platform identifies them (API 29+); failed configuration attempts fall through to other AVC decoders. Older APIs report acceleration as unknown. Codec name/flag are telemetry, not proof of phone performance.
- Playback follows presentation timestamps, loops at EOS, drops moderately late frames, and resynchronizes after stalls over 500 ms so a delayed start does not discard an entire loop indefinitely. Clock recoveries and dropped frames are reported. A slow device may still stutter or take longer than ten wall-clock seconds per loop.
- Off-page, movement, zoom mismatch, lock, invalid calibration and timeout gates suppress video. Visibility loss and gating stop the decode pump, flush queued video, and reset the loop for resume. No render timer runs while invisible. Surface loss closes the decoder, SurfaceTexture and EGL resources.
- Diagnostics include first submitted video frame, codec/acceleration flag, source metadata, rendered/decoded/dropped frames, loops, pauses, active-time FPS, frame-gap statistics, clock recoveries and the user's observation. Counters cover the current wallpaper renderer lifetime, including retries. They do not measure thermal behavior or certify every transition.
- The guided flow preserves prior successful A/B/C observations across an engine-only restart. It still requires a fresh two-tap measurement on the original page-A widget, identical launcher/display/surface configuration and matching page-A offset including steps. Layout/display changes require repeating the survey. Stored observations remain explicitly human-reported.

Technical references: [MediaCodec](https://developer.android.com/reference/android/media/MediaCodec), [SurfaceTexture](https://developer.android.com/reference/android/graphics/SurfaceTexture), [MediaCodecInfo](https://developer.android.com/reference/android/media/MediaCodecInfo). No new permissions or network access are added. The synthetic emulator prerequisite helper exists only in the separate test APK.
