# 0.5.0 — local video and GIF selection

- System ACTION_OPEN_DOCUMENT picker accepts video and GIF MIME types without new storage permission. The selected URI is copied on a worker thread into an app-private temporary file with a byte cap, then inspected and atomically published under a unique name. A failed copy/validation leaves the previous selection intact. Original files are never modified. Orphaned private imports/old copies are cleaned at the next process start, before a renderer exists.
- MediaPolicy validates video dimensions/duration/FPS/rotation, bounds file copying, and structurally parses GIF dimensions, sub-blocks, frames and trailer before native decode. GIF decode-work budget is 16 million canvas-pixels × frames. Imported video decoder availability is checked, with actual decode failures reported at playback. No transcoding is performed.
- Existing MediaExtractor/MediaCodec/SurfaceTexture compositor now reads the selected private video, preserving hardware preference and fitting the rotated output dimensions. Audio tracks are not selected. Bundled clip remains available separately. Source changes release the old decoder and reset source counters. A missing first video frame times out after ten seconds of active playback attempts. Media errors stop playback and allow a new selection rather than permanently poisoning EGL.
- GIFs use Android Movie for explicit timed offscreen rendering on the compositor thread, compatible with the existing API-26 floor. This legacy API is deprecated on newer Android but retained here for a single software-Canvas path; no claim of hardware GIF decode is made. Premultiplied-alpha GL blending preserves transparency over the static wallpaper. Only changed GIF frames upload, capped at about 30 checks per second. Hidden/off-page playback pauses and resets the loop.
- Personal playback uses the existing measured page-A rectangle and 150 ms settling gate, has no diagnostic timeout, and hides guide labels/border. Tap opens controls through the existing capture path, which can require remeasurement if the position changed. Restarting the wallpaper still clears active mode and requires a fresh position; this update does not weaken geometry validity.
- Setup leads directly to animation selection. File constraints, import errors and Stop are on the same screen. A private file survives source removal and app/process restarts. The older diagnostic observation flow remains optional.

References: [Android document access](https://developer.android.com/training/data-storage/shared/documents-files), [Movie](https://developer.android.com/reference/android/graphics/Movie), [MediaFormat rotation](https://developer.android.com/reference/android/media/MediaFormat#KEY_ROTATION). See VALIDATION.md for executed evidence and limitations.
